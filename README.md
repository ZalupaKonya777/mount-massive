# Mount Massive · Прибытие

**[Играть в браузере](https://zalupakonya777.github.io/mount-massive/)** — iPhone / iPad (Safari), Android (Chrome), ПК.

Поверните телефон горизонтально, нажмите **«Загрузить игру»**, затем **«Играть»** и **«Начать»**.
После остановки машины: **ДЕЙСТВИЕ** — открыть папку, **Закрыть** — убрать письмо, ещё **ДЕЙСТВИЕ** — взять видеокамеру, затем **ДЕЙСТВИЕ** — выйти.

Левый стик — движение, свайп справа — обзор. БЕГ / ПРИСЕСТЬ переключаются нажатием. ДЕЙСТВИЕ — двери и предметы; ВЫШЕ — контекстный подъём и преодоление препятствия. КАМЕРА — поднять камеру; НОЧЬ — ночное видение; БАТАРЕЯ — сменить батарею. II — пауза, включая финальную сцену.

Звук включается касанием «Играть». После прерывания аудио появляется кнопка восстановления звука. Safari с Audio Session API использует режим playback; для старых iOS предусмотрен media fallback. Громкость регулируется кнопками телефона. Через «Поделиться → На экран Домой» на iPhone можно добавить значок игры. Для загрузки нужен интернет.

Текущий уровень: ревизия 2, финал 3 с моделью Криса из предоставленного Tripo GLB, захватом из щели, разбитием стекла и физическим падением на нижний этаж.

Играбельный учебный прототип по видеореференсу Outlast; проект не связан с Red Barrels. Планировка скрытых участков, материалы и анимация приблизительные. Исходное видео и библиотека предоставленных моделей не опубликованы. Звуки созданы для прототипа. Источники материалов: [ASSET_CREDITS.md](ASSET_CREDITS.md).

103 проверки маршрута и 32 проверки сенсорного контроллера. Браузерные проверки Chromium и WebKit включают реальный выход Web Audio, восстановление контекста, сохранение и финал. **Физический iPhone/Android здесь не тестировался**; WebKit на Linux не является проверкой конкретного телефона. Результаты и SHA-256: [build_info.json](build_info.json).

В однопоточном Godot 4.3 применён обход ошибки culling при большом числе объектов. В Linux WebKit остаются native glBlitFramebuffer-диагностики; изменение реальных пикселей комнаты при NV проверяется отдельно. Подмена GL-вызовов в сборке не используется.
